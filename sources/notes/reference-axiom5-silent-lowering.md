T_flat (the flattener flattened over itself) shipped for weeks without core/bmf-core/bmf-grammar/host-effect-grammar in its module list: `host-effect-op?` inside it was an unresolved call recovered to literal 0, so effect-bound do-lets in defns lowered as inline re-evaluations (read_line re-fired per USE) and every carrier the fkwu self-host arm authored was aphonic (2026-07-17, receipts/2026-07-17-regen-lane-healed-anesthesia-lifted.md).

**The general trap:** stamps hash SOURCES, not artifacts — a fossil or mis-authored committed artifact passes every stamp check; shape validation passes on a mute table; axiom-5 recovery makes missing closure SILENT. Sibling of the [[silent-partial-list-family]].

**Second shape — paraphasia (2026-07-17, receipts/2026-07-17-fourth-arm-paraphasia-float-to-str.md):** on the fourth arm an UNBOUND call name lowers numb to a call returning POOL STRING 0 — not silence, a fluent wrong word ("cell", the shim's first literal). fourth-shim.fk mirrors core.fk but a mirror gap (float_to_str) meant json-emitter emitted `cell` where `1.25` belonged — same byte length, so str_len probes read clean; only byte-level diffing exposed it. Probe: `(zz-definitely-unbound 1)` vs pool[0]. One wrong word can drop several verdict bits downstream (invalid JSON → parser stops → later fields vanish).

**Third shape — printed-error laundering (2026-07-17, receipts/2026-07-17-exit-truth-printed-error-laundering.md):** fkwu --src printed 8 axiom-5 `[unresolved-call] error:` lines yet exited 0 with no tally — the SPECULATIVE per-dep standalone image compile (fk_src_try_import_fkb_images) diagnosed loudly, its image was rejected by the recorded-errors gate, and fk_src_reset_compile_state wiped fk_nerr before the clean flat compile. Healed by splitting per-compile counters from monotone PRINTED counters (fk_nerr_seen/fk_nwarn_seen, never reset): speculative compiles are quiet, the rejection is one counted warning, tally + exit read the printed counters. Law name: exit-truth (corpus row 813 — minted 802, renumbered twice the same hour: behind five sibling lineages to 812, then behind paraphasia to 813); band: observe/tests/src-exit-truth-band.fk (GREEN 2047 / RED 1713 pre-fix).

**Fourth shape — verdict-parity numbness (2026-07-18, receipts/2026-07-18-jit-bands-closure-parity.md):** fkwu `--src` preludes resolution is PER-UNIT-CLOSURE: each dep compiles against its OWN transitive `; preludes:` closure, NOT against siblings the root file loaded earlier — a band listing form-asm before a dep does not make the dep see form-asm; the dep needs its own live line (dead capital `; Prelude:` blocks don't count, but they document the true dep list to derive live lines from). 22 jit bands answered their exact documented all-ones masks while hundreds of calls sat numb — `nothing == nothing` comparisons stay green. Never accept verdict equality alone: demand verdict equality PLUS zero `[unresolved-call]` diagnostics (A/B against the one-text cat pipeline, which resolves everything in-unit). Corpus row 807: parity.

**Fifth shape — load-order cataphora (2026-07-18, 120-divergence triage):** the T_flat band-flatten path (fourth_band_request → fkwu walking T_flat) binds cross-module FORWARD references numb-empty at read time, while the three walkers late-bind — so a band's `; preludes:` ORDER changes meaning on exactly one arm. jit-lower-emit's dependents-first header flattened fkc-emit-universal to 3,272 of 101,588 chars (fourth 31 vs 63); fsh-fnri-staged's answered 0 vs 7/7/7. Heal at the band: dependency-first, full transitive closure in the header (the fourth arm does NOT expand transitive headers — validate.sh's bash resolver does, only for the three walkers). Sibling shape in the BML source compiler: a top-level multi-line statement never joins in the line reader and compiles "successfully" with a glued token (`list(`) baked into the .fkb — all three kernels then die at walk_recipe_here; inside a def-block the same shape works (reader slurps to the brace). Both have open deeper-heal tasks (loud-or-resolve).

**Sixth shape — loanclosure (2026-07-21, receipts/2026-07-21-q6k-stride-verified-loanclosure-heal.md, corpus row 829):** the per-unit rule has a treacherous inverse — a LOADER's incidental prelude can pay a callee's debt, so the same recipe is voiced in one band and numb in another. `form-asm-matvec.fk` declared only `form-asm.fk` while calling `append` (core.fk — form-asm.fk has only `append-list`) and `f64-bytes` ×18; block-join-asm-band carried core.fk itself so `append` resolved there, form-asm-matvec-band didn't. Fixing that ONE prelude line moved 19 bands to their header-declared full verdicts (u=23→0), four of which had been printing **0** — a wholly silent band, nothing red. So: when a band under-claims its documented verdict, suspect a callee's incomplete prelude before suspecting the band; and grep `grep -rln <cell> --include=*.fk` for every loader to size the radius. A verdict that MOVES on a prelude fix is the expected outcome, not a regression — gate on "each band reaches its own `; Verdict N when every claim lands:` line", not on verdict equality.

**Seventh shape — unreached-call-site numbness (2026-07-28, receipts/2026-07-28-panel-review-and-the-numb-green.md, corpus row 921):** fkwu resolves EVERY call site in a prelude chain, not only the reached ones — so a cell that runs on fkwu (needs `host-exec`) and preludes a cell carrying a `walk_recipe` call site *in a function it never calls* raises 2 `[unresolved-call]`, exits 1, and still prints its full green verdict (`cognition/tests/gen-conformance-band.fk`: 255, exit 1). No reading touched those sites, so the fold was right and numb. **Heal by splitting cells along the ARM boundary**, not by silencing: arm-neutral half (tables/renderer/emitters) stays and is preluded by any arm; sibling-only half (`walk_recipe`) moves out with the band check that reads it — `gen-neutral-walk.fk` / `gen-query-walk.fk`. A cell should prelude only doors its own arm has. Found by a review panel that ran the band and read the exit status; I had read only the number.

**Common-mode caveat (corpus row 921):** four-way kernel agreement guards against INDEPENDENT error only. Three implementations of one semantics written by one hand (here: `gcf-expected`, the graph's hand accessors, the emitters) are one channel drawn three times — they drift together and print green. Four-way green is not evidence about shared assumptions.

**Eighth shape + the two lane heals (2026-07-31, receipts/2026-07-31-flatten-lane-closure-crossed.md, corpus row 937 reducerepair):** the fifth shape's "fourth arm does NOT expand transitive headers" is HEALED — `fourth_band_srcs` (scripts/fourth-arm.sh) now expands `; preludes:` recursively (post-order dependency-first, dedup, owner-dir-first resolution mirroring `fk_resolve_dep_path`), and form-flatten.fk's unknown-call arm emits `form_error` carrying `flt-unresolved-call: <name>` (pool-free byte_to_str/str_concat nodes) instead of the numb `fk-lit 0`. The eighth shape is what forced it: voice-render-band answered 511/1535 vs 2047 while TEN faithful reductions crossed green, because every fresh reduction file re-derived its header complete — a defect the act of reducing silently repairs (`reducerepair`). When every faithful reduction is green, diff what the reproducer INHERITS vs what it RE-DERIVES.

**How to apply:** (1) when regenerating any self-hosted image (T_flat, bootstrap tables), verify its module list carries the FULL prelude closure of what it flattens — compare against the walking chain; (2) gate regenerated artifacts with a behavior canary (ping→pong / effect-let-used-twice), never stamps+shape alone — regen_t_flat.sh and regen_form_cli_bootstrap.sh now carry these; (3) a single-use let cannot distinguish framed from inlined — a discriminating probe needs the binding used TWICE; (4) form-cli's module graph lives in SIX list copies (build-form-cli.sh ×3, regen_form_cli_bootstrap.sh ×3-ish, regen_standard_lane_binaries.sh ×1) — count them all when grafting.
